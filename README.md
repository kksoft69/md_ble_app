# MD 무선 진동 센서 BLE 앱

Android Chrome용 오프라인 PWA입니다. Raytac의 BLE 광고가 켜져 있으면 인터넷이나 CM4 연결 없이 센서에 직접 접속하여 통계, 상태, 이벤트, raw 파형을 보고 설정을 변경할 수 있습니다.

## 설치

1. 인터넷이 연결된 Android Chrome에서 `https://kksoft69.github.io/md_ble_app/`을 엽니다.
2. **오프라인 실행 준비 완료** 표시를 확인하고 **휴대폰에 앱 설치**를 누릅니다. 버튼이 없으면 Chrome 메뉴의 **앱 설치**를 선택합니다.
3. Wi-Fi와 모바일 데이터를 끄고 Bluetooth를 켠 뒤 홈 화면의 **MD 센서 BLE**를 실행합니다.
4. **센서 연결**에서 `MD-VIB`를 선택합니다.

설치에는 최초 한 번 HTTPS 접속이 필요합니다. 앱 파일은 서비스 워커가 기기에 저장합니다. BLE 광고가 OFF인 센서는 오프라인 상태에서 휴대폰으로 켤 수 없습니다.
